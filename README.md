# Load Prediction using Random Forest and Decision Tree

## 📌 Project Overview

This project focuses on **Load Prediction** using Machine Learning classification/regression techniques. Two different machine learning algorithms are implemented and compared:

* 🌳 Decision Tree
* 🌲 Random Forest

The main purpose of this project is to understand how Decision Tree and Random Forest algorithms perform on the same dataset and to compare their prediction results.

## 📂 Dataset

**Dataset:** `load prediction dataset for RF.csv`

The dataset contains features related to load prediction that are used to train the machine learning models.

## 🤖 Machine Learning Algorithms

### 1. Decision Tree

Decision Tree is a supervised machine learning algorithm that makes predictions by creating a tree-like structure based on different features.

### 2. Random Forest

Random Forest is an ensemble learning algorithm that combines multiple decision trees to produce more reliable and accurate predictions.

## 🔧 Project Workflow

The following steps were performed in this project:

1. Imported the required Python libraries.
2. Loaded the dataset using Pandas.
3. Explored and understood the dataset.
4. Performed data preprocessing and cleaning.
5. Selected the required features and target variable.
6. Split the dataset into training and testing sets.
7. Trained the **Decision Tree** model.
8. Trained the **Random Forest** model.
9. Generated predictions using both models.
10. Evaluated and compared the model performance.

## 📊 Model Evaluation

The models were evaluated using appropriate performance metrics such as:

* Accuracy Score
* Confusion Matrix
* Classification Report

The performance of **Decision Tree** and **Random Forest** was compared to understand which model provides better results on the given dataset.
